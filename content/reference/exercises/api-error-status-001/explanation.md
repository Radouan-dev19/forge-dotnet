# Explication

Mettre les erreurs connues sur liste blanche et rabattre les détails internes vers 500. La solution sépare validation et décision, sans état externe. Complexité : **O(n) en temps et O(n) en espace**. Les cas cachés varient les frontières et réfutent une constante mémorisée. Après lecture, la tentative n’est pas maîtrisée : expliquez la règle avec vos mots et planifiez une reprise à blanc.
