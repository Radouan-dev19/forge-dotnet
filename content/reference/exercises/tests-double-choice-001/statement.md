# Choisir un double de test

Implémentez Submission.DoubleKind avec la signature fournie. Choisir spy pour l’interaction, fake pour le comportement et stub pour une réponse.

La décision reste déterministe et hors ligne, sans instancier aucun double. Écrivez avant le code : les quatre combinaisons des deux besoins, en vérifiant laquelle prime lorsqu'ils sont vrais tous les deux. Nommez ce qu'une vérification d'appel ajoute lorsqu'un résultat est déjà vérifié.

Exemple : entrée `[false,false]`, sortie `"stub"`.
