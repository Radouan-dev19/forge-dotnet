# Normaliser une saisie locale

Implémentez Submission.NormalizeInput avec la signature fournie dans starter/Submission.cs.

Retirer seulement les espaces de bord sans modifier le contenu interne. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `["  Ada  "]`, sortie `"Ada"`.
