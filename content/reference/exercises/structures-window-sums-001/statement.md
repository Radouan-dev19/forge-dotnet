# Calculer des fenêtres glissantes

Implémentez Submission.WindowSums avec la signature fournie dans starter/Submission.cs.

Ajouter l’entrant, retirer le sortant puis publier chaque fenêtre complète. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
