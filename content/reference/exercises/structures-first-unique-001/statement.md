# Trouver le premier caractère unique

Implémentez Submission.FirstUnique avec la signature fournie dans starter/Submission.cs.

Compter puis reparcourir dans l’ordre d’origine pour choisir le premier. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
