# Explication

Compter puis reparcourir dans l'ordre d'origine pour choisir le premier.

Deux parcours sont nécessaires et suffisants. Le premier établit les comptes ; le second choisit, et c'est lui qui porte la notion de « premier ». Chercher la réponse dans le dictionnaire une fois les comptes établis donnerait un caractère unique, pas le premier : l'ordre d'un dictionnaire n'est pas un contrat.

Un seul parcours ne peut pas conclure, puisqu'un caractère vu une fois peut réapparaître plus loin. C'est le cas d'école d'un problème dont l'information n'est complète qu'à la fin. Le temps reste linéaire et l'espace croît avec le nombre de caractères distincts.
