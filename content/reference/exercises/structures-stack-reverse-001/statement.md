# Inverser avec une pile

Implémentez Submission.ReverseText avec la signature fournie dans starter/Submission.cs.

La pile restitue les caractères dans l’ordre inverse sans perdre les espaces. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
