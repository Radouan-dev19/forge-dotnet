# Appliquer une liste blanche de tri

Implémentez Submission.NormalizeSort avec la signature fournie. Retourner seulement une clé publique autorisée et choisir id par défaut.

La normalisation reste déterministe et hors ligne, sans construire aucune requête. Écrivez avant le code : une clé autorisée, la même dans une autre casse, une clé inconnue et une valeur absente. Nommez ce qu'une clé concaténée sans liste fermée permettrait d'injecter.

Exemple : entrée `["date"]`, sortie `"date"`.
