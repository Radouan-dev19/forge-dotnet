# Rechercher linéairement

Implémentez Submission.IndexOf avec la signature fournie dans starter/Submission.cs.

Retourner la première position ou moins un après un parcours complet. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
