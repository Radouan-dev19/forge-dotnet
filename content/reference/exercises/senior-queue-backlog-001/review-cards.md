# Cartes de révision

- **Qu'est-ce qui résorbe l'arriéré d'une file : la consommation ou autre chose ?** Le débit net —
  consommation moins arrivées : les producteurs continuent pendant le drainage, et diviser par la
  consommation brute annonce une file vide bien trop tôt.
- **Pourquoi doubler les consommateurs ne double-t-il presque jamais le temps gagné ?** Parce que le
  gain porte sur le débit net : quand consommation et arrivées sont proches, le doublement
  démultiplie le net ; quand elles sont éloignées, il ne change presque rien.
