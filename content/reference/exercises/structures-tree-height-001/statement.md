# Calculer une hauteur depuis les parents

Implémentez Submission.TreeHeight avec la signature fournie dans starter/Submission.cs.

Suivre les parents jusqu’à la racine et refuser un cycle par une garde bornée. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
