# Évaluer une porte de déploiement

Implémentez Submission.CanDeploy avec la signature fournie. Exiger simultanément preuves vertes, environnement protégé et approbation.

La décision reste déterministe et hors ligne : aucun système de déploiement n'est interrogé. Écrivez avant le code : la porte ouverte, puis les trois cas où une seule condition manque. Nommez ce qu'une porte qui n'a jamais bloqué personne vérifie réellement.

Exemple : entrée `[true,true,true]`, sortie `true`.
