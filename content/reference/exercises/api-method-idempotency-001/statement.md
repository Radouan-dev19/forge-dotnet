# Reconnaître une méthode idempotente

Implémentez Submission.IsIdempotent avec la signature fournie. Comparer une méthode normalisée à la liste explicite des méthodes idempotentes.

La classification reste déterministe et hors ligne, sans émettre aucune requête. Écrivez avant le code : une méthode idempotente, la méthode de création qui ne l'est pas, et une méthode écrite en minuscules. Nommez ce qu'un client peut réessayer sans risque grâce à cette propriété.

Exemple : entrée `["GET"]`, sortie `true`.
