# Tester des partitions de remise

Implémentez Submission.DiscountRate avec la signature fournie. Couvrir chaque partition et les frontières exactes cent et deux cents.

Le calcul reste déterministe et hors ligne, sans consulter aucun catalogue. Écrivez avant le code : une valeur par partition, les deux paliers exacts, la valeur juste en dessous de chacun, et un montant négatif. Nommez ce qu'un test qui ne touche aucun palier ne peut pas détecter.

Exemple : entrée `[99.99]`, sortie `0`.
