# Compter les ancêtres d’un nœud

Implémentez Submission.AncestorCount avec la signature fournie dans starter/Submission.cs.

Valider chaque parent et borner le parcours pour détecter un cycle. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
