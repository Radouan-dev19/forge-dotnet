# Compter des anomalies de seuil

Implémentez Submission.AnomalyCount avec la signature fournie dans starter/Submission.cs.

La borne est strictement dépassée et Abs utilise long pour Int32.MinValue. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée $(Convert-JsonCompact System.Object[] System.Object[][0]), sortie $(Convert-JsonCompact System.Object[] System.Object[][1]).
