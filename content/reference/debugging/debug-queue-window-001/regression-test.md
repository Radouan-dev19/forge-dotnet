# Non-régression

Couvrir une fenêtre plus petite que l'historique, une fenêtre égale à l'historique, une fenêtre plus grande, une fenêtre nulle et un historique vide. Le jeu doit échouer sur `broken/Submission.cs` dès que la fenêtre est plus petite que l'historique et réussir sur `correction/Submission.cs`.
