# Base commandes mini-ERP

Modéliser commandes et clients, écrire les requêtes S8–S10 et démontrer reset, tracking, N+1 et concurrence.

Le livrable comprend le contrat, le code écrit par l’apprenant, des tests utiles, un journal d’un défaut reproduit puis corrigé et une défense de dix minutes. Toute assistance est déclarée. Aucune solution complète n’est fournie avant soumission.
