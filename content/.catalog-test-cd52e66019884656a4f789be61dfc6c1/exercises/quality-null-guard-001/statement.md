# Rendre une garde nullable explicite

Implémentez Submission.NormalizeOptional avec la signature fournie. Traiter absence et blanc avant toute déréférence, sans opérateur de suppression.

La normalisation reste déterministe et hors ligne. Écrivez avant le code : une valeur ordinaire, une valeur entourée de blancs, une chaîne uniquement composée de blancs, et une valeur absente. Nommez ce qu'un opérateur d'affirmation déplace de la compilation vers l'exécution.

Exemple : entrée `[" value "]`, sortie `"value"`.
