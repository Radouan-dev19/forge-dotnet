# Calculer un décalage paginé

Implémentez Submission.SkipCount avec la signature fournie. Valider page et taille avant un calcul vérifié du décalage.

Le calcul reste déterministe et hors ligne, sans émettre aucune requête. Écrivez avant le code : la première page, une page intermédiaire, le refus d'un numéro nul et celui d'une taille hors plage. Nommez ce que l'oubli de la soustraction ferait disparaître d'un jeu de résultats.

Exemple : entrée `[1,20]`, sortie `0`.
