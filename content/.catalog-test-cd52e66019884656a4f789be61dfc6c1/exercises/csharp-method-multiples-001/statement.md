# Compter les multiples d’une plage

Implémente `public static int CountMultiples(int start, int end, int divisor)`.

Compte les entiers divisibles par `divisor` entre `start` et `end`, bornes comprises. Si `start > end`, retourne `0`. Un diviseur négatif est accepté et donne le même résultat que sa valeur positive. Un diviseur nul doit provoquer `ArgumentOutOfRangeException`.

Les bornes sont comprises entre -1 000 et 1 000. Décris le contrat de chaque paramètre avant l’implémentation.
