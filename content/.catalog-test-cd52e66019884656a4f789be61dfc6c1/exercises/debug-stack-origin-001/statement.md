# Extraire la première frame applicative

Implémentez Submission.FirstFrame avec la signature fournie dans starter/Submission.cs.

Ignorer les frames système et conserver la première frame applicative dans l’ordre. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `["at System.X\nat Forge.Order.Run"]`, sortie `"at Forge.Order.Run"`.
