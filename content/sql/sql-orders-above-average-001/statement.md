# Comparer à une sous-requête scalaire

Écrivez une requête bornée qui retourne `OrderId` et `Total` pour les commandes dont le montant dépasse la moyenne de toutes les commandes, ordonnées par identifiant.

La moyenne se calcule sur l'ensemble, pas par client. N'utilisez ni objet serveur, ni référence inter-base, ni donnée externe.
