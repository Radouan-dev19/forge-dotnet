# Projeter les clients actifs

Écrivez une requête bornée qui retourne `CustomerId` et `Name` pour les seuls clients actifs, ordonnés par identifiant.

Le drapeau d'activité se lit sur la table des clients : aucune jointure vers les commandes n'est nécessaire pour décider. N'utilisez ni objet serveur, ni référence inter-base, ni donnée externe.
