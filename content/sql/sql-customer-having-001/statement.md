# Filtrer les groupes par HAVING

Écrivez une requête bornée qui retourne `CustomerId` et `OrderCount` pour les seuls clients ayant au moins deux commandes, ordonnés par identifiant.

Le filtre porte sur le résultat du regroupement, pas sur les lignes d'origine. N'utilisez ni objet serveur, ni référence inter-base, ni donnée externe.
