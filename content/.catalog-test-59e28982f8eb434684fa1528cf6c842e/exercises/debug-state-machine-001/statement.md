# Rejouer des transitions bornées

Implémentez Submission.FinalState avec la signature fournie dans starter/Submission.cs.

Appliquer seulement les transitions autorisées et ignorer les événements hors état. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `[[1,2]]`, sortie `2`.
