# Cartes de révision

- **Pourquoi une preuve de jalon se date-t-elle par rapport au dernier changement ?** Parce qu'une
  preuve est une photographie du code à un instant : le correctif poussé ensuite coupe le lien entre
  la preuve et ce qui part, et le dossier devient trompeur, pas incomplet.
- **Pourquoi distinguer une preuve périmée d'une preuve absente dans le verdict ?** Parce que la
  correction diffère : la périmée se rejoue, l'absente se produit — le verdict qui les fond oblige à
  rouvrir le dossier pour savoir quel travail lancer.
