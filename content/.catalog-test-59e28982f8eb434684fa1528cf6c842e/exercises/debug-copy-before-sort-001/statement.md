# Préserver les données observées

Implémentez Submission.SortedCopy avec la signature fournie dans starter/Submission.cs.

Trier uniquement une copie afin que Watch et l’appelant conservent l’état initial. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `[[3,1]]`, sortie `[1,3]`.
