# Sommer une plage inclusive

Implémente `public static int SumInclusive(int start, int end)` avec une boucle.

Lorsque `start <= end`, additionne tous les entiers de `start` à `end`, bornes comprises. Lorsque `start > end`, retourne `0`. Les tests utilisent des bornes entre -1 000 et 1 000, de sorte que le résultat tient dans un `int`.

Ne change ni la classe ni la signature. Écris d’abord l’invariant du cumul : ce que `total` représente après chaque itération.
