# Filtrer sans dépendre de la culture

Implémentez Submission.ContainsTerm avec la signature fournie. Refuser les termes vides puis utiliser une comparaison ordinale insensible à la casse.

Le filtre reste déterministe et hors ligne, sans dépendre de la culture de la machine. Écrivez avant le code : une correspondance exacte, une correspondance de casse différente, et le refus d'un terme vide. Nommez ce qu'un terme vide accepté retournerait à l'appelant.

Exemple : entrée `["Commande Ada","ada"]`, sortie `true`.
