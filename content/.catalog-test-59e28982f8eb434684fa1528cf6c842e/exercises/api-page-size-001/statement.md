# Borner une taille de page

Implémentez Submission.ClampPageSize avec la signature fournie. Appliquer une valeur par défaut positive et un plafond strict de cent.

Le calcul reste déterministe et hors ligne, sans lire aucun réglage externe. Écrivez avant le code : une taille raisonnable, le plafond exact, le plafond dépassé d'une unité, et une taille nulle. Nommez ce qu'une taille non bornée permettrait de faire au serveur avec une seule adresse.

Exemple : entrée `[25]`, sortie `25`.
