# Structurer un bref dʼincident en anglais

Implémentez Submission.IncidentBriefStatus avec la signature fournie. Un bref est prêt seulement sʼil nomme lʼimpact, cite une preuve et attribue la prochaine action.

La décision reste déterministe et hors ligne : aucune source distante n'est interrogée. Écrivez avant le code : le bref complet, puis les trois cas où un seul élément manque. Nommez ce qu'un compte rendu sans action attribuée change dans l'organisation.

Exemple : entrée `[true,true,true]`, sortie `"ready"`.
