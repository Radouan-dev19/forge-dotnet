# Masquer une valeur sensible

Implémentez Submission.Redact avec la signature fournie. Ne conserver aucun caractère du secret et produire au moins quatre marqueurs.

La rédaction reste déterministe et hors ligne, et n'emploie aucune valeur ressemblant à un secret réel. Écrivez avant le code : une valeur ordinaire, une valeur plus courte que le minimum de marqueurs, et une valeur vide. Nommez ce qu'un masque partiel laisserait déduire.

Exemple : entrée `["fake-key"]`, sortie `"********"`.
