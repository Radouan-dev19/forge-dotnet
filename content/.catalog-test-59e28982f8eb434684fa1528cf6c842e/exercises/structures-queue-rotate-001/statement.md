# Faire tourner une file

Implémentez Submission.RotateQueue avec la signature fournie dans starter/Submission.cs.

Normaliser le nombre de rotations et préserver l’ordre FIFO. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `[[1,2,3],1]`, sortie `[2,3,1]`.
