# Normaliser un segment de route

Implémentez Submission.NormalizeRoute avec la signature fournie. Retirer seulement les séparateurs de bord et normaliser avec une culture invariante.

La normalisation reste déterministe et hors ligne, sans consulter aucune table d'acheminement. Écrivez avant le code : un chemin déjà propre, un chemin bordé de séparateurs, un chemin à segments internes, et une chaîne de blancs. Nommez ce qu'une fusion de segments produirait côté client.

Exemple : entrée `[" /Orders/ "]`, sortie `"orders"`.
