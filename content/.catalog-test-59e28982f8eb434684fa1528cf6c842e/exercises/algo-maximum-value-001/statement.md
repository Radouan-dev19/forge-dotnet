# Calculer le maximum signé

Implémentez Submission.Maximum avec la signature fournie dans starter/Submission.cs.

Initialiser depuis le premier élément pour respecter les tableaux négatifs. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `[[3,1,2]]`, sortie `3`.
