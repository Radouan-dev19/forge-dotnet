# Borner un budget d’annulation

Implémentez Submission.EffectiveTimeout avec la signature fournie. Valider les durées puis retenir le budget le plus contraignant.

Le calcul reste déterministe et hors ligne. Écrivez avant le code : une demande plus courte que le plafond, une demande plus longue, l'égalité exacte entre les deux, et le refus d'une durée nulle. Nommez ce qu'un budget non borné laisserait consommer.

Exemple : entrée `[5,30]`, sortie `5`.
