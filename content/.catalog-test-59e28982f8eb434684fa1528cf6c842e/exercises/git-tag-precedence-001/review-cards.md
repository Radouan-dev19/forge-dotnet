# Cartes de révision

- **Pourquoi comparer les segments comme des nombres.** Dans l'ordre du dictionnaire, la dixième
  correction précède la neuvième, et le pipeline déploie une version périmée.
- **Pourquoi s'arrêter au premier écart.** Un majeur supérieur signifie une rupture ; poursuivre
  laisserait un segment mineur renverser une décision déjà prise.
