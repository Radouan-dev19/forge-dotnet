# Détecter une frontière

Implémentez Submission.IsBoundary avec la signature fournie. Refuser des bornes incohérentes puis comparer exactement les deux frontières.

La détection reste déterministe et hors ligne. Écrivez avant le code : chacune des deux extrémités, une valeur intérieure, une valeur extérieure, et le refus de bornes inversées. Nommez l'erreur que le triplet autour d'un seuil attrape et que la seule valeur du seuil laisserait passer.

Exemple : entrée `[1,1,100]`, sortie `true`.
