# Cartes de révision

- **Pourquoi le partage se teste en premier.** C'est une interdiction, pas une préférence : testée
  après le bruit, une branche partagée serait écrasée et ses commits survivraient en doublons chez
  les collègues.
- **Ce que l'écrasement détruit.** Il jette le cheminement pour garder le résultat ; quand les
  commits racontaient une progression utile, cette information est perdue définitivement.
