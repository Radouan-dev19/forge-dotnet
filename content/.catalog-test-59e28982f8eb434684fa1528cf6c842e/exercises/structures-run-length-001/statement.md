# Compter les groupes consécutifs

Implémentez Submission.RunCount avec la signature fournie dans starter/Submission.cs.

Incrémenter seulement lors d’un changement par rapport au caractère précédent. Le résultat doit être déterministe, hors ligne et ne doit pas modifier les entrées. Avant de coder, écrivez le cas nominal, une borne et un cas qui réfute une réponse codée en dur.

Exemple : entrée `["aaabb"]`, sortie `2`.
