# Cartes de révision

- **Qui classe, qui départage ?** La qualité demandée par le client ordonne les candidats ; l'ordre
  du serveur n'intervient qu'entre deux qualités égales.
- **Une qualité nulle** est un refus explicite. Une entrée exacte à zéro écarte le type, même en
  présence d'un passe-partout qui l'autoriserait.
