# Non-regression

Tester une sequence sans changement d'ecran, une sequence avec un changement d'ecran au milieu, et une
sequence avec une fermeture explicite. Le cas avec changement d'ecran doit echouer avant la correction,
le compteur restant trop haut, et reussir apres, le compteur retombant a zero pour les abonnements de
l'ecran quitte.
