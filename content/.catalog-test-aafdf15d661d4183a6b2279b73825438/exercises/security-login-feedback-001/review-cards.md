# Cartes de révision

- **Jusqu'où s'étend l'uniformité du message public de connexion ?** Jusqu'à la preuve du mot de
  passe : compte inconnu, compte verrouillé et mot de passe erroné partagent un message ; seule
  l'expiration, atteignable après la preuve, se nomme.
- **Pourquoi le journal de connexion garde-t-il les causes exactes ?** Parce que les défenseurs
  distinguent un utilisateur maladroit d'une pulvérisation de mots de passe par la signature des
  causes — et l'attaquant, lui, ne lit pas le journal.
