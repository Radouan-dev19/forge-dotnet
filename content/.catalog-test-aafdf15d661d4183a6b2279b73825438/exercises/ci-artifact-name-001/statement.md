# Nommer un artefact de façon stable

Implémentez Submission.ArtifactName avec la signature fournie. Normaliser la branche, remplacer le séparateur et exiger un numéro positif.

La composition reste déterministe et hors ligne : aucun système de construction n'est interrogé. Écrivez avant le code : une branche simple, une branche contenant un séparateur de chemin, une branche en majuscules, le plus petit numéro accepté, et un numéro nul. Nommez ce qu'un nom d'artefact permet de retrouver six mois plus tard.

Exemple : entrée `["main",42]`, sortie `"tests-main-42"`.
