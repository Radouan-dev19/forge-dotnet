# Cartes de révision

- **Pourquoi le fichier partagé prime sur l'écart.** Deux cents commits qui ne touchent aucun fichier
  commun n'interfèrent pas ; trois commits sur la même fonction peuvent avoir déplacé les lignes visées.
- **Ce qu'un report sans conflit ne prouve pas.** Le conflit est un signal syntaxique : le commit peut
  s'appliquer proprement et dépendre d'un comportement qui a changé sur la branche cible.
