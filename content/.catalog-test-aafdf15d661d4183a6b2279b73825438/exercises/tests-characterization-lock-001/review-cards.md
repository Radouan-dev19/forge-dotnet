# Cartes de révision

- **Que fige un test de caractérisation ?** Le comportement réellement observé du code hérité,
  bizarreries et refus compris — jamais la règle documentée, qui a divergé depuis longtemps.
- **Pourquoi ne pas corriger un défaut découvert pendant la caractérisation ?** Parce que le
  référentiel doit rester une photographie : une correction silencieuse rend indistinguables les
  régressions du remaniement et les écarts volontaires.
