# Borner une mémoire de conteneur

Implémentez Submission.ClampMemoryMb avec la signature fournie. Choisir 256 par défaut puis borner toute valeur explicite entre 128 et 1024 Mo.

Le calcul reste déterministe et hors ligne : aucun conteneur n'est exécuté. Écrivez avant le code : une demande dans l'intervalle, les deux bornes exactes, une demande en dessous du plancher, une au-dessus du plafond, et une demande nulle. Nommez ce qu'une limite trop basse produit et ce qu'une limite absente produit.

Exemple : entrée `[512]`, sortie `512`.
