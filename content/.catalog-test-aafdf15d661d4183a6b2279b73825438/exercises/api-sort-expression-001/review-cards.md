# Cartes de révision

- **Pourquoi un ordre total ?** Trier par un champ non unique ne fixe pas l'ordre relatif de deux
  lignes égales ; une page peut alors répéter une ligne ou l'omettre sans qu'aucune donnée ait changé.
- **Pourquoi refuser un champ hors liste blanche plutôt que l'ignorer ?** Parce que le client croirait
  lire des données triées et déciderait sur un ordre qui n'a jamais été appliqué.
