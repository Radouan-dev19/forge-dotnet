# Choisir un type adapté

Cette fixture vérifie que le corps Markdown d'une leçon est présent, local et sans HTML brut.

Elle porte aussi un bloc de code clôturé, car une leçon publiée doit montrer la notion qu'elle
annonce et non se contenter de la décrire.

```csharp
decimal montant = 19.99m;   // decimal : arithmétique décimale exacte, adaptée à une monnaie
double mesure = 19.99;      // double : arithmétique binaire approchée, adaptée à une mesure
```
