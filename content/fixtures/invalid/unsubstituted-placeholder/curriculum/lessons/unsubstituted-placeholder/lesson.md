# Marqueur non substitué

## Prérequis

Relire la leçon précédente $previousLessonId avant de poursuivre cette activité.

## Intuition

Le générateur laisse ici une variable non évaluée : le lecteur reçoit un prérequis inexploitable.

## Explication

Un marqueur de gabarit publié tel quel est un défaut de contenu, pas une fonctionnalité.

```csharp
int total = 1 + 1;
```
